1) Разархивируйте папку из файла .rar в любое удобное место.

2) После чего, зайдя в папку, нажимаете на файл «UDF» ПКМ -> открыть с помощью -> выбрать другое приложение -> Найти другое приложение на этом компьютере -> Теперь ищите файл AutoHotkeyU32.exe (У меня он сохранён по обычному пути: C:\Program Files\AutoHotkey\v1.1.37.02\AutoHotkeyA32.exe) 

3) Выберите также чтобы открывалось всегда с помощью этого приложения 

4) Открываете файл Akiyama.ahk и можете редактировать информацию под себя. Часть АХК можно настроить только через блокнот.

* АХК создан и для фамилий, и для позывных. Фамилия ставится туда же, куда и позывной.
